# Bounded fresh review

Use [the review procedure](review.md) with one fresh native reader when consequence or uncertainty warrants it and the host and session permit delegation. Follow [orchestration](../overlays/orchestration.md): provide the intended behavior, constraints, scoped artifacts, read-only authority, return format and stop condition. Disclose shared context and give the reviewer actual files rather than only the builder's summary. No grandchildren, competing writers or duplicate reviews of the same scope.

The implementing agent verifies findings and owns corrections and affected checks. If a native reviewer is unavailable or unauthorized, report the gap and explicitly choose direct review at a task boundary; do not claim fresh review or silently substitute it. This selection installs instructions, not an agent runtime or new permissions.
