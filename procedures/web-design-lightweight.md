# Bounded frontend design

Use the pinned [Anthropic frontend-design reference](../sourced/anthropic/design/instruction.md) for a bounded change within an existing surface. Preserve project truth, visual intent, components and accessible behavior. Read only the relevant guidance; it grants no installation, delegation or deployment authority.

Inspect the built page and affected states, make the smallest coherent change, then check keyboard access, responsive layout, reduced motion and errors with the current browser tools. For a new visual identity or broad critique, propose the guided procedure at a checkpoint rather than silently loading a second primary workflow. Deterministic tests and screenshots remain different from human approval.
