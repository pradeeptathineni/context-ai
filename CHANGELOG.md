## [0.1.0] - 2026-09-12

### Added

- Nine concise provider-independent contexts for engineering, context design, compression, development, research, testing, review, benchmarking, and versioning.
- Root `AGENTS.md` routing guidance and a current OpenAI Codex adapter.
- Central provenance map, context-evaluation protocol, dependency-free validator, and GitHub Actions validation.

### Changed

- Refined the existing model-routing policy into a documented schema with current OpenAI bindings, explicit matching semantics, and source review metadata.
- Expanded the public README around progressive disclosure, layer boundaries, usage, and release scope.
