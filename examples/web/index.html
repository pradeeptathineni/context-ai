Verbose output
Choose context-output before the first large read or command. It captures once and retrieves bounded evidence. Native reads need their own limits.
Test-first repair
Choose context-tdd when a stable public seam needs a failing regression test. Direct upstream and Context tied correctness in the CSV trial; native used fewer calls and tokens.
Preview, use, refresh or remove a focused selection

Run from the Context source with its source-local Python environment. Replace /absolute/project with your consumer path. For TDD, replace context-output with context-tdd.

.venv/bin/python scripts/context_ai.py plan --with context-output --project /absolute/project --provider both
.venv/bin/python scripts/context_ai.py apply --with context-output --project /absolute/project --provider both
.venv/bin/python scripts/context_ai.py verify --project /absolute/project

Inspect the preview before apply. Verify checks installed files; it does not run the task. For output, explicitly read the installed .context-ai/resources/procedures/output.md before use. Then run from the consumer:

python3 .context-ai/resources/scripts/context_output.py run --log NEW_RAW.log -- COMMAND
python3 .context-ai/resources/scripts/context_output.py inspect NEW_RAW.log --query error

The view is partial. Expand a relevant query or range if the cause is missing. Raw bytes and command status survive; a nonzero command still returns nonzero. General token savings and human usefulness remain unproven.

From the Context source, refresh previews an update; apply it at a task checkpoint. Undo removes unchanged owned files and preserves edits and private logs:

.venv/bin/python scripts/context_ai.py refresh --project /absolute/project
.venv/bin/python scripts/context_ai.py undo --project /absolute/project

Report what you actually read, invoked and checked. Installation alone does not establish use or benefit. This page runs none of these commands.
