# Representative web exercise

This is a public synthetic consumer fixture, independent from neon1. The visitor is a developer finding which Context AI loadout fits a job. They should identify a starting point, filter it, and inspect a web verification checklist. No install or remote submission occurs.

Direction: a calm reading surface with strong type and divided catalogue rows. An expressive green/dark variant demonstrates explicit brand latitude without changing hierarchy. The compared alternatives were an identical-card landing page and a dense command console; the chosen reading surface makes the catalogue easier to compare and keeps guidance understandable.

Tokens live in style.css: one system type family, a responsive heading scale, cool neutral surfaces, restrained blue accent, fluid spacing and clear focus. The fixture deliberately uses available system fonts for deterministic offline rendering and no asset/license/network burden; upstream display-font taste is advisory. The variant uses a bounded dark/green palette rather than decorative animation. No generated or third-party assets are used.

Acceptance: built/static output, 320/390/768/1440px, both palettes, no overflow, clear keyboard focus/skip link, filter/empty/reset, disclosure, truthful local note error/success, preserved note input, reduced motion, axe, no browser errors, <=24 KB total delivered bytes. Full-page captures need visual inspection and a critique/revision pass. No claimed production CWV, human usefulness or assistive-technology approval.
