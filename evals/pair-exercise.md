# Signals to Context pair exercise (2026-10-07)

**Input.** Real post-reset Signals exports from `pradeeptathineni/signals-ai@8b744cb` (export revision; the original research revision was not recorded): a one-candidate agent-assisted bundle (SHA-256 `0ce4754c640b3cead232552625a4882c02caea883b4b5f556f42481d95119b71`, Neoma) and a six-candidate model-led bundle (`b1a5e339c4b596330f2a331c19f5e6f3f80a185912659ff7c1247b3eda67af13`). Both admitted by `scripts/evidence.py` with the pinned producer; a `signals-recommendation-v2` envelope, a wrong producer commit and a wrong digest were each rejected. Source observation dates are null in schema v1, so freshness is reported unknown; Signals' fetch times stay in its opaque extension.

**Decision.** Need: offline, portable research notes for a Markdown-in-Git consumer whose existing owner is plain Markdown. Context's own inspection of Neoma at `18c63fb` (AGPL-3.0-or-later, no install hooks, Markdown canonical, upstream import/export/link tests passing) was supplied as an assessment; `scripts/adoption.py` returned **trial** for Neoma (adoption only after a passing trial; trial authority not granted by the tool) and **reject** for all six other candidates, each addressing a different capability, including two with producer action `use`.

**Delivery and use.** `plan` (no writes) then `apply research-evidence --with context-portable-notes --provider claude`: Neoma's compatibility document and license, unmodified, plus the thin Context procedure. One Claude Code run (claude-sonnet-5-5, 11 turns, 49 s, signed-in subscription; $0.15 client estimate, not a bill) read the router, the procedure and the pinned Neoma reference, then wrote three notes. It did not call the Skill tool.

**External check.** A harness running Neoma's own `extractNoteMeta`, `LinkGraph` and vault ZIP export/import under Node found, after the task, 5 notes, all three sources present with body links, 0 broken links, every new note backlinked and a byte-identical re-import. The same check failed on the unchanged consumer.

**Undo and independence.** `undo` refused while a pinned file had a user edit, preserved it, then removed everything once resolved; a user line added to AGENTS.md survived and the notes still passed the check. Context selection, apply, verify and undo ran with a minimal environment and no Signals checkout; a missing bundle fails only the adoption command. A crafted high-score `use` recommendation with proprietary license and app runtime was rejected, an unsupported claim stayed at study, and `--with neoma` was refused: evidence cannot install itself.

**Limits.** One run, builder-designed task and check, documentation-only delivery; Neoma's browser UI and folder vaults were not exercised. This shows a working Signals-to-consumer path, not a measured benefit over plain Markdown.
